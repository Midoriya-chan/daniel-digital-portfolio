## Run Locally

1. Clone this repository, or open your existing local GitHub project in **Visual Studio Code**.
2. Open the `daniel-desiderio-portfolio-premium` folder.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and select **Open with Live Server**.
5. Review the site on both desktop and mobile screen sizes.

No `npm install`, framework setup, or build command is required.

## Deployment

This repository is intended to deploy through **GitHub → Netlify**. When connecting the GitHub repository in Netlify, use:

| Setting | Value |
| --- | --- |
| Repository | `Midoriya-chan/daniel-digital-portfolio` |
| Production branch | `main` |
| Base directory | Leave empty |
| Build command | Leave empty |
| Publish directory | `daniel-desiderio-portfolio-premium` |

Once connected, new commits pushed to `main` will trigger a Netlify deployment. Add the confirmed public Netlify URL to the top of this README after the first successful deployment.

### Update and Publish

Make changes locally in VS Code, then run these commands from the **Git repository root**:

```bash
git add .
git commit -m "Update portfolio content and design"
git push origin main
```

Netlify will deploy the latest pushed version if continuous deployment is connected and enabled.
